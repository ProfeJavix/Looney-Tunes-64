This is a naming guide for Looney Tunes 64 character voicelines. Read the following points for better understanding:
-The quoted text on the left is the file name, where "Char" is replaced by the character's name (eg: Bugs Hello.ogg, don't add the quotes to the file name). The text on the right is a description of where the clip will be played.
-EVERY DESCRIPTION MUST BE USED, but not every clip must be different. You can use a clip for many descriptions (eg: "Char Wah.ogg" for Second Punch and Ground Pound, or "Char Coughing.ogg" for every coughing take). If that's the case, please specify which descriptions are targetted by the clip in its name
-A description can use many clips. If that's the case, add a number at the end of the text (eg: "Char Sound Uh2_2.ogg", "Char Sound Uh2_2 2.ogg", "Char Sound Uh2_2 3.ogg" and so. Note the white space before the number)
